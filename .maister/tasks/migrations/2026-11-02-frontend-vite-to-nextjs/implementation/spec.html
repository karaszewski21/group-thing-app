TL;DR

  • 13 commit checkpoints on main. The behaviour-changing prep lands first on Vite, guarded by the ~920-case suite: the full features/ reorganisation (D7), SSR-safety fixes, the navigation facade in src/routing/, and the auth cookie.
  • The Next swap only re-implements a few seams. proxy.ts rewrites / → /home for cookie holders (D6), redirects /home → /, gates private prefixes and routes POST /oauth2/authorize to the backend.
  • Public pages get server generateMetadata plus the palette from anonymous fetches, and backend OG and the catch-all are removed. The backend reads the cookie on GET/HEAD only, sends Vary: Authorization, Cookie and reserves home.
  • No regression means: Vitest pass-set ⊇ A0, pytest/ruff unchanged, mypy ≤ 15, next build + typecheck clean, and the Playwright smoke checklist.

Technical depth

Navigation facade API (A3)
  • Link (to, replace, state, scroll) · Navigate · useAppNavigate() (consults the guard; -1 = back)
  • useAppParams() (catch-all → "*") · useAppSearchParams() (functional setter, scroll:false) · useAppSearch()
  • useAppPathname() = normalizeAppPath (/home → /)
  • useHasInAppHistory() (NavigationTracker) · useNavigationState() (consumed once) · useRouterRefresh()
  • useNavigationGuard(shouldBlock) → {state, proceed, reset}
  • renderWithRoute(ui, {url, pattern, routes}), getTestLocation(), getTestRouter(): MemoryRouter in A3, the alias-mocked next/navigation in B3
Auth cookie (A4 frontend, A5 backend)
  • Cookie: auth_token; Path=/; SameSite=Lax; Max-Age = exp − now; Secure on https; not HttpOnly
  • Write points: login, register, applyExternalToken, logout, 401 handler, AuthGuard stale path
  • Reconciliation: a valid localStorage token wins → else a valid cookie is copied → else both are cleared; refresh() on change
  • Backend: cookie only for GET/HEAD, after header, _token query and form; Vary: Authorization, Cookie; GET routes verified non-mutating
Server metadata and palette (C1) · backend cleanup (C2)
  • api/server.ts: server-only, anonymous, no-store, React cache(), null on error
  • Org: "Strona organizacji {name}." + cover · Event: "{weekday} DD.MM o HH:mm" [· place] [description] + banner · Term: "Najbliższy termin: DD.MM.YYYY." [description] or "Dołącz i zobacz najbliższe spotkania."
  • og:type website; twitter summary_large_image with an image, else summary
  • ServerThemeProvider: display:contents vars + context; OrganizerThemeScope uses theme ?? initialTheme
  • C2: delete public_preview.py, preview routes, spa_fallback, test_public_preview.py; add a JSON 404 test; matrix re-check
Deploy (D)
