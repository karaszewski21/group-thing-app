TL;DR

  • Locality search (name, postal code, Polish-letter folding, towns first) and the two-field place form work. Places save with or without an address.
  • The + → /places/new round trip keeps the draft and selects the new place in 7 forms. History is unchanged and the stepper reopens.
  • Privacy holds: non-owners and anonymous visitors get {locality, formatted_address:null, deleted_at:null}, and no address appears in the page, HTML or API.
  • One Minor issue: the photo preview is blank after Anuluj on /places/new (the file is still kept).

Key Decisions

  • Restarted the stale uvicorn (no /api/localities) and the stale Next dev server (SSR 500s); everything was re-run on fresh servers.
  • Migrated the local DB to head without a backup, as the user authorised: 54,440 localities and 72,245 postal codes in 1.66 s.
  • The Maps key is not set, so only manual address entry was verified. The transfer guard was checked through the API.

Open Questions / Risks

  • 'Nowa Huta' matches villages, not the Kraków district.
