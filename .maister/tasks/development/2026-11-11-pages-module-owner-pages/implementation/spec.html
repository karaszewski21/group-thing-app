TL;DR

  • The seven public owner-page reads move from app/groups into a new layered, read-only package app/pages (router/, application/, domain/, infrastructure/, schemas.py); URLs, responses, operationIds, cache headers and statement counts stay the same, only the OpenAPI tag becomes pages.
  • Groups keeps its rules, SQL and events reads and exposes 14 more names through groups.service; pages composes them through six pure re-export ACLs.
  • pages/domain/ gets three small pure modules: page content (layout keys and row caps), public link paths, and the merge rule for an owner's upcoming dates.
  • Two new test files (boundary guard with three tests, domain rules with three); three existing test files get import edits and the clock guard gets one directory entry.
  • Work is done in an order that keeps the tree importable and the suite green after every step; the pages router is registered in the same step that removes the groups one. mypy and ruff are judged against baselines recorded in step 0 (15 mypy errors; ruff is not clean today), not against "clean".

Key decisions

  • domain/page_content.py holds PageLayout and all eight row caps — constants with no dependency; one module because two tests and both application modules read them.
  • domain/links.py (term_path, event_path) and domain/owner_dates.py (merge_upcoming_dates) are extracted as pure functions — rules with no db; output identical to today's inline code.
  • Application layer is two modules, organization_page.py and owner_pages.py, and the router mirrors them — same split as today's two source files.
  • _counts becomes owner_item_counts — returns OwnerItemCountsResponse, sits next to owner_summary, no collision with the repository's count_owner_*_by_mode queries.
  • groups/application/owner_items.py keeps its file name with four functions — item_actions.py:42 stays untouched.
  • Route and schema docstrings move verbatim — FastAPI publishes them as OpenAPI descriptions, and the acceptance rule is "OpenAPI unchanged except the tag".
  • pages/infrastructure/locations_acl.py re-exports load_locations_by_ids as get_locations_by_ids — no wrapper, no extra statement.
  • The guard test also holds pages/domain/ to "no app.* import at all".
  • The guard test checks the ACL files for one thing only: none imports app.pages.schemas — a few lines on top of the import resolver the file already has. "Each <x>_acl.py imports only app.<x>" is not checked by a test; it needs a file-to-context mapping and is left to review.
  • merge_upcoming_dates is declared with PEP 695 type-parameter syntax — the TypeVar(...) form fails ruff UP047 under target-version = "py312".
  • Module docstrings of the two moved application modules are rewritten for the new location; function docstrings move verbatim — module docstrings are not published in OpenAPI and the source text is stale.
  • ruff and mypy pass or fail against baselines recorded in step 0, and ruff format is never run on a file that is unformatted at baseline — the tree has 69 ruff check findings and 50 unformatted files today; reformatting them would bury the move in an unrelated diff.

Scope

Goal. Give the public owner pages their own read-only module with an enforced boundary, without changing anything a client of the API can observe except the OpenAPI tag.

In scope
  • The move of the seven routes, their application code and 17 schema classes + alias
  • Six pure re-export ACLs; three pure domain modules
  • 14 new groups.service exports, 2 removed
  • Boundary guard test, domain test, clock guard extension
  • Removal of two groups ACL wrappers and two dead functions
  • Docs: architecture.md, time.md, INDEX.md
Out of scope
  • Any behaviour, response, URL, status-code, cache-header or DB change; migrations; frontend
  • Renaming or copying schema classes; fixing stale route docstring wording
  • Moving derive_party_slug; an exchange module; renaming circulation; unifying organizers/organizations prefixes
  • A direct pages → events or pages → circulation ACL
  • Replacing the path f-strings that remain inline in groups
  • Full package-tree refresh in architecture.md; automated OpenAPI snapshot test; a new standard for page modules
  • Commits

Backend developer

I want the public owner pages in app/pages so that app/groups holds only groups rules and I can find page composition in one place.

Backend developer

I want a test that fails when another package imports app.pages, or when page code reaches another context outside pages/infrastructure/, so that the boundary does not erode.

Frontend developer / API client

I want the seven URLs to behave exactly as before so that nothing on my side changes.
