CosmeticC2 — „Moje punkty” meta shows a bare „20”

No unit, so the accessible name is „Moje punkty 20”. Fix: render „{balance} pkt”.

CosmeticC1 — Admin inputs and buttons unstyled (pre-existing)

The points config and the existing category form both render borderless inputs and plain-text buttons. Fix the admin Chakra recipes in a separate task.

CosmeticC4 — Non-admin sees the admin shell with an English „Access denied” (pre-existing)

The backend correctly returns 403; /admin/groups behaves the same. Add an admin layout permission gate in a separate task.
